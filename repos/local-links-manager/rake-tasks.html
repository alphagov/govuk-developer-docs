local-links-manager: Rake tasks

These rake tasks come from the desc descriptions in local-links-manager’s lib/tasks folder. To change what’s shown here, change the description in the code.

unlock

Unlock lock

k exec deploy/local-links-manager -- rake unlock

View source (lib/tasks/remove_lock.rake)

service:enable

Enable or create a service.

k exec deploy/local-links-manager -- rake service:enable[lgsl,lgil,label,slug]

View source (lib/tasks/service.rake)

service:destroy

Destroys an existing Service and all dependant records

k exec deploy/local-links-manager -- rake service:destroy[lgsl_code]

View source (lib/tasks/service.rake)

check-links

Check all links for enabled services

k exec deploy/local-links-manager -- rake check-links

View source (lib/tasks/check-links/link_checker.rake)

check-links:local_authority

Check links & update link status for a single local authority

k exec deploy/local-links-manager -- rake check-links:local_authority[authority_slug]

View source (lib/tasks/check-links/link_checker.rake)

check-links:all_local_authorities

Check links & update link status for all active local authorities.

k exec deploy/local-links-manager -- rake check-links:all_local_authorities
More about this task 
This will run in the background as a queue of Sidekiq jobs.
The jobs will take a long time to complete, even a few hours.

View source (lib/tasks/check-links/link_checker.rake)
