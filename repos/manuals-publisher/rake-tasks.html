manuals-publisher: Rake tasks

These rake tasks come from the desc descriptions in manuals-publisher’s lib/tasks folder. To change what’s shown here, change the description in the code.

delete_draft_manual

Delete draft manual, or discard the draft of a previously published manual (supply EITHER manual_slug OR manual_id)

k exec deploy/manuals-publisher -- rake delete_draft_manual[manual_slug,manual_id]

View source (lib/tasks/delete_draft_manual.rake)

delete_duplicate_drafts

Delete duplicate drafts

k exec deploy/manuals-publisher -- rake delete_duplicate_drafts

View source (lib/tasks/delete_duplicate_drafts.rake)

View source (lib/tasks/dev.rake)

relocate_manual

Relocate manual from <from-slug> to <to-slug>

k exec deploy/manuals-publisher -- rake relocate_manual[from_slug,to_slug]
More about this task 
Both <from-slug> and <to-slug> need to be published manuals

View source (lib/tasks/relocate_manual.rake)

reslug_manual

Change the slug of a manual (and its sections) from <old_slug> to <new_slug>.

k exec deploy/manuals-publisher -- rake reslug_manual[old_slug,new_slug]
More about this task 
The old URLs are redirected to the new ones by the Publishing API.
Example: rake "reslug_manual[guidance/old-manual,guidance/new-manual]"

View source (lib/tasks/reslug_manual.rake)
