signon: Rake tasks

These rake tasks come from the desc descriptions in signon’s lib/tasks folder. To change what’s shown here, change the description in the code.

k exec deploy/signon -- rake access_tokens:renew_expiring_internal_tokens

View source (lib/tasks/access_tokens.rake)
