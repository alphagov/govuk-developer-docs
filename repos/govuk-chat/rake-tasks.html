govuk-chat: Rake tasks

These rake tasks come from the desc descriptions in govuk-chat’s lib/tasks folder. To change what’s shown here, change the description in the code.

bigquery:export

Run an export of data to Bigquery

k exec deploy/govuk-chat -- rake bigquery:export

View source (lib/tasks/bigquery.rake)

bigquery:backfill_table

Backfill an export of a particular table up until last exported until

k exec deploy/govuk-chat -- rake bigquery:backfill_table[table_name]

View source (lib/tasks/bigquery.rake)

bigquery:delete_table

Delete a table from BigQuery

k exec deploy/govuk-chat -- rake bigquery:delete_table[table_name]

View source (lib/tasks/bigquery.rake)

bigquery:reset

Delete all of our known Big Query tables and our data of exports

k exec deploy/govuk-chat -- rake bigquery:reset

View source (lib/tasks/bigquery.rake)

bigquery:delete_opted_out_end_user_data

Delete all BigQuery exports for an opted-out user

View source (lib/tasks/bigquery.rake)
